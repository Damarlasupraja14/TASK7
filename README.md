# 📊 TASK 7: Basic Sales Summary using SQLite and Python

---

## ✅ Objective
The goal of this task is to:
- Use SQL within Python to extract basic sales information from an SQLite database.
- Display results using print statements and a simple matplotlib bar chart.

---

## 🛠 Tools & Libraries Used
- Python
- SQLite (via `sqlite3`)
- Pandas
- Matplotlib

---

## 📂 Dataset
A small SQLite database `sales_data.db` was created manually with one table named `sales`, containing the following columns:
- `product` (TEXT)
- `quantity` (INTEGER)
- `price` (REAL)
